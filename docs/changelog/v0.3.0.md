# v1.2.0 — Lowercase project rename

**Released:** 2026-04-07

---

## What changed

### Project identifiers are now fully lowercase

All technical identifiers for the project have been normalised to lowercase `flourish`:

| Identifier | Before | After |
|-----------|--------|-------|
| Source directory | `Flourish/` | `flourish/` |
| Product name | `Flourish` | `flourish` |
| App bundle | `Flourish.app` | `flourish.app` |
| Xcode scheme | `Flourish.xcscheme` | `flourish.xcscheme` |
| Bundle identifier | `com.personal.flourish` | unchanged |

Swift type names (`FlourishApp`, `FlourishColors`, etc.) retain PascalCase per Swift conventions and are not affected.

---

### `project.yml` gains an explicit `schemes:` block

`project.yml` now declares the scheme explicitly:

```yaml
schemes:
  flourish:
    build:
      targets:
        flourish: all
    run:
      config: Debug
    archive:
      config: Release
```

Previously, no scheme was declared, leaving `flourish.xcscheme` to be created by Xcode on first open. The explicit declaration ensures `make generate` produces a correctly-named scheme immediately without requiring an Xcode open step.

---

## Why

Lowercase identifiers are the convention for Unix paths, bundle IDs, and repository names. The Title-Case default from Xcode's project wizard was inconsistent with the bundle identifier and the GitHub repository name (`personal-stuff/flourish`). See [ADR-022](../app/adr/022-lowercase-project-name.md) for the full rationale.

---

## Impact / risk

- **No user-visible change.** The app's display name and UI copy are unaffected.
- **No API or data-model change.**
- **Developer action required if you have a local clone:** run `make clean && make generate` to regenerate the Xcode project with the correct lowercase scheme. If you see a Xcode warning about `flourish.app` vs `Flourish.app` capitalization mismatch, delete the stale entry from `~/Library/Developer/Xcode/DerivedData/` and clean the build folder (Shift+Cmd+K).

---

## Migration

```bash
make clean && make generate
```

Optionally remove any stale global DerivedData:

```bash
rm -rf ~/Library/Developer/Xcode/DerivedData/Flourish-*
```
