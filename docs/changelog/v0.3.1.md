# v1.2.1 — Pricing update

**Released:** 2026-04-07

---

## What changed

### Pro plan pricing reduced

The Pro plan prices have been updated:

| Billing period | Before | After |
|----------------|--------|-------|
| Monthly | 12 € / month | 2,99 € / month |
| Annual | 10 € / month (billed annually) | 29,99 € / year (~16% off monthly) |

The discount badge on the Annual option in the Account view now reads **-16%** (was -17%).

---

## Why

Pricing adjusted to match the current market positioning and early-adopter strategy.

---

## Impact / risk

- **User-visible change:** The prices shown in the Account → Billing section are lower.
- **No API or data-model change.** Stripe Price IDs are configured in `wrangler.toml` as Cloudflare secrets (`STRIPE_MONTHLY_PRICE_ID`, `STRIPE_YEARLY_PRICE_ID`). The Worker and app code are unchanged; only the displayed labels and the Stripe product configuration need updating.
- **Stripe action required:** Update the active Price objects in the Stripe dashboard (or create new ones and rotate the secrets in Cloudflare) to reflect the new amounts before promoting this release.

---

## Migration

No app migration required. Update Cloudflare secrets if the Stripe price IDs change:

```bash
wrangler secret put STRIPE_MONTHLY_PRICE_ID
wrangler secret put STRIPE_YEARLY_PRICE_ID
```
