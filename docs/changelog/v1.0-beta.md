# v1.0-beta — First distributable release

**Released:** 2026-04-07  
**Git tag:** `v1.0-beta`  
**Distribution:** `flourish-1.0-beta.dmg`

---

## Summary

First DMG release of flourish. Packages the complete application — overlay workflow, Supabase auth, Stripe billing, usage tracking, guideline profiles, history, and statistics — into a distributable installer for macOS 13+.

---

## What's included

### Core prompt-improvement workflow
- Global hotkey (default Ctrl+Space) opens a non-activating floating overlay from any app.
- Improved prompt is pasted back into the previously-focused app via Cmd+V simulation.
- 3-dot pulsing loader during LLM calls; success checkmark on paste.
- Draft persistence across dismissals; history navigation via Up/Down in the overlay.
- Rotating playful placeholders in the overlay input.

### Authentication and accounts
- Sign-in panel on launch (Supabase Auth — magic link).
- Account view: usage meter, current plan badge, upgrade/manage billing.
- Monthly limit reached: floating popup blocks the overlay until the cycle resets or the user upgrades.

### Billing and usage
- Free plan: 30 improvements/month. Pro plan: unlimited.
- Stripe-powered checkout and portal via the Cloudflare Worker.
- Usage tracked in Supabase PostgreSQL; JWT-verified on every request.

### Guideline profiles
- 6 built-in outcome-oriented profiles (Clearer, More Concise, More Detailed, Professional, Developer, Creative).
- Unlimited custom profiles.
- AI-generated profile suggestions via `ProfileGeneratorService`.

### Target platform formatting
- Per-platform formatting instructions appended to the system prompt (Chat, Code, Email, Docs, Social, Generic).

### History and statistics
- SQLite history (max 500 entries) via GRDB.
- Per-session and all-time cumulative stats.

### Distribution
- Ad-hoc signed DMG with custom sage-green background, app icon, and "Drag to install" arrow.
- `build-dmg.sh` is the single source of truth for the version string — interactive prompt detects the last DMG and asks for the new version before stamping `Info.plist` and building.

---

## Installation

1. Open `flourish-1.0-beta.dmg`.
2. Drag `flourish.app` to the Applications folder.
3. Right-click → **Open** on first launch to bypass Gatekeeper (ad-hoc signing — no notarization).
4. Grant Accessibility permission when prompted (required for paste automation).

---

## Known limitations

- Light mode only.
- No streaming output — response delivered all at once.
- Accessibility permission must be granted manually on first use.
