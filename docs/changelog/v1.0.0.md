# v1.0.0 — Initial Release

**Released:** 2026-04-06

## Summary

First public version of Flourish. Introduces the complete prompt-improvement workflow: a global-hotkey overlay, dual LLM provider support, guideline profiles, SQLite-backed history, and a full-window management UI.

## Features Introduced

### Overlay Workflow
- Global hotkey (default Ctrl+Space) opens a non-activating floating panel from any app.
- TextEditor input auto-focuses; Return submits, Shift+Return adds a newline, Escape dismisses.
- 3-dot pulsing loader panel displays during LLM call.
- Improved text is written to clipboard and pasted into the previously focused app via Cmd+V simulation.
- Original clipboard contents are restored after paste.

### Draft Persistence
- Dismissed drafts (without pasting) are saved to UserDefaults and restored on next overlay open.
- Draft timestamp is displayed when restored.

### History Navigation in Overlay
- Up arrow in the overlay loads the previous history entry (most recent first) from the last 50.
- Down arrow returns toward the draft.
- Current draft is saved before entering history mode and restored when returning.

### LLM Provider Support
- **OpenRouter**: Aggregator supporting Gemini, GPT-4, Claude, Llama, Mistral, Qwen families.
- **Groq**: LPU-accelerated inference with free-tier Llama and Mixtral models.
- Both providers use the OpenAI-compatible Chat Completions API.
- Provider selected per-session in the overlay toolbar.

### Guideline Profiles
- 6 built-in profiles: Clearer, More Concise, More Detailed, Professional, Developer, Creative.
- Unlimited custom profiles with arbitrary system prompt text.
- Last selected profile remembered across sessions.

### History Store
- SQLite database via GRDB at `~/.local/share/com.personal.flourish/history.db`.
- Max 500 entries; oldest auto-deleted on overflow.
- Full-text search on original and improved prompts.
- Per-entry metadata: provider, model, token counts, estimated cost, timestamp.

### Statistics
- Per-session stats (request count, tokens in/out, cost) via `SessionStatsTracker`.
- All-time cumulative stats persisted in UserDefaults.
- Stats badges displayed on the Home screen.

### Main Window
- Sidebar navigation: Home, Profiles, Settings.
- Home: hero card with overlay CTA + history timeline grouped by TODAY/YESTERDAY/EARLIER.
- Profiles: CRUD interface for custom profiles.
- Settings: integrated scrollable panel covering Providers, Keyboard Shortcut, Base Prompt, and General preferences.

### Security
- API keys stored in macOS Keychain (never in UserDefaults or on disk).
- Ad-hoc code signing (no Apple developer account required).

### General
- Launch at login toggle.
- Show/hide dock icon toggle (default: menu bar agent only, no dock icon).
- Connection test button per provider.
- Custom base prompt template with `{guidelines}` placeholder.

## Known Limitations

- Light mode only (no dark mode support in this release).
- No streaming/progressive output — response is delivered all at once.
- Accessibility permission must be granted manually on first use.
- History search uses SQL `LIKE` (case-insensitive substring); no full-text index (FTS5).
